# ULTRON Panel 2.1 - Windows

Version de Windows de ULTRON Panel.

## Instalacion

La forma mas sencilla es descargar:

`dist/UltronSetup-v2.1.exe`

El instalador prepara automaticamente Python, el entorno de ULTRON, las dependencias necesarias y FFmpeg si hacen falta.

Durante la primera instalacion se necesita conexion a Internet.

## Ejecutar desde el codigo

1. Ejecuta `INSTALAR-ULTRON-WINDOWS.bat`.
2. Despues abre `INICIAR-ULTRON-WINDOWS.bat`.

## IA

ULTRON usa la variable local `GROQ_API_KEY`. Ninguna clave API se incluye en este repositorio.

## Seguridad

Este repositorio no incluye archivos de secretos, identidad local, entornos virtuales, caches, backups ni memoria privada del usuario.
